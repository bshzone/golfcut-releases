# GolfCut — golf highlight video maker for Windows

GolfCut is a Windows app that finds the shots, greens and group moments in golf round footage (GoPro, DJI and other action cams on a tripod) and makes a highlight mp4 with one button. It runs on your PC: nothing is uploaded, and there is no file-size or length limit. A free edition is available; Pro is a one-time purchase.

GolfCut은 액션캠으로 찍은 골프 라운드 영상에서 샷·그린·일행 장면을 자동으로 찾아 버튼 하나로 하이라이트 mp4를 만드는 Windows 앱입니다. 영상은 PC 밖으로 나가지 않습니다.
