# GolfCut — downloads

GolfCut은 액션캠으로 찍은 골프 라운드 영상에서 샷·그린·일행 장면을 자동으로 찾아 하이라이트 mp4로 만드는 Windows 앱입니다. 영상은 PC 밖으로 나가지 않습니다.
GolfCut is a Windows app that finds shots, greens and group moments in action-cam golf footage and exports a highlight mp4. Your video never leaves your PC.
